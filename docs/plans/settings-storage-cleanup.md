# 设置页与存储清理

用户已确认移除设置页「自动化」分组，并允许清理已启用软件源的旧包和重复包。
仅移除该设置入口，现有后台任务及偏好值继续使用原来的实现。

三个清理入口保持可点击；没有可清理内容时明确提示。实际删除前显示数量与确认，
清理结束刷新空间统计，按实际成功数反馈，失败保留重试入口并显示原因。

- 旧副本：按 Bundle ID 与签名日期比较，只删除早于最新可用签名包的副本，
  不按显示名归组，不把最新包或没有可用替代包的包删除。
- 重复导入：只清理同 Bundle ID、同来源版本已有可用签名副本的导入包；
  手动导入按相同且非空版本判断。待签名的新版本、其他源/订阅变体保留。
- 归档：只清理 Documents/Archives 中的导出文件，保留目录、证书和应用包。
- 禁用/已删除订阅、签名/安装/下载任务使用中的应用，以及持久化安装清理计划
  涉及的输入、旧包和签名结果均保护；安装结束后按已有策略解锁。

实施顺序：先补纯 Swift 清理策略、真实文件清理和安装保留回归；移除自动化 UI，
将 StorageView 接入策略及可报告错误的删除接口；完成模拟器 UI 与受影响回归、
iOS 构建和文档同步；push 开发提交并提交协调器 ready，读取同一发布凭证验收双渠道。

本地验收（2026-10-14）：清理策略回归、OneView 6 项回归、安装保留与真实 Core Data
保存失败重试回归、自动签名/直接安装队列回归通过；模拟器构建及 `make iphoneos`
完成。独立审查补齐手动入口持久化保护、旧格式计划兼容、连续签名接替和独立待安装
计划的自动清理保护，相关回归通过。

真实 App 界面使用隔离的 10 个测试包验收：移除 1 个启用来源旧包、1 个同版本导入包
及 1 个导出归档；其余 8 个最新/新版本/禁用/待安装包与关联记录、证书保留。
