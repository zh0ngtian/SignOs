# 软件源添加与管理入口收敛

用户于 2026-10-13 确认：先用公开 URL 添加软件源，需要管理时再在该源设置中填写 Token；不支持管理的源隐藏设置齿轮；移除管理页中的“订阅到 SignOs”和二级“软件源设置”。

实现沿用 `CloudSourceEndpoint.managementURL(for:)` 的现有管理地址识别规则，不增加服务端能力或改变 Token 保存、订阅同步、源身份检查。管理页仅接受已添加源及其管理地址，继续提供 Token 连接、分享地址、立即同步、订阅管理和本机移除。二级名称/简介编辑页与重复添加源逻辑一并删除。

普通源隐藏齿轮后，原先的移除入口也会消失。因此软件源列表卡片提供长按“移除软件源”与确认弹窗，沿用原有禁用和删除处理；不让普通源失去移除能力。
