# 应用页合并与跨源更新

适用版本：SignOs 1.1.0（22）起；软件源安装按钮样式自 1.1.3（25）统一；应用卡片按软件源发布日期排序自 1.1.12（34）生效。本记录取代此前讨论过的软件源 Bundle ID 排他和手动导入双向互斥方案。

## 页面和版本基线

底部导航为软件源、应用、设置。应用页的已签名包按实际 Bundle ID 汇总，原始未签名包归入其本机配置目标 ID 的卡片；不同 Bundle ID 的已签名包和克隆仍是独立应用。全部列表保持紧凑，可更新筛选显示完整更新说明和全部更新，待安装筛选显示只有未签名包的应用。搜索匹配名称和 Bundle ID。

应用卡片按软件源当前版本的发布时间从新到旧排列，全部、可更新、待安装及搜索结果共用此顺序。多源应用取启用且未删除订阅的当前候选版本中最新的发布时间；已是最新版、暂停更新和跳过版本不影响日期参与排序。不使用本地导入、签名、检查时间或历史旧版本日期。日期相同按应用名称、Bundle ID 稳定排列；没有来源或缺少发布时间的应用排在有日期的应用之后。冷启动取得当前会话软件源候选后、下拉检查更新后以及来源开关变化后自动重排。

可更新卡片展示所选来源/订阅从当前来源版本（不含）到目标版本（含）的全部更新日志，按语义版本从新到旧排列，每条使用现有分隔线。每条标明版本，在软件源右侧显示该版本发布时间（设备区域格式的日期与时间）；缺少日期显示“发布时间未知”，空日志显示“未提供更新说明”。筛选基线优先使用本地包保存的来源版本，避免 IPA 内版本不同造成遗漏。只展示软件源实际提供的历史；其他来源/订阅的日志不混入，重复版本只展示一次，旧格式单版本源继续展示目标版本。

从软件源页面选择同一来源/订阅、同一版本和下载地址的包时，复用当前本地基线对应的已检查候选，保留完整日志快照；只有来源信息的临时候选不能覆盖已取得的跨版本日志。

最近一次成功签名的保留包作为“已安装”展示基线，按签名日期而非最高版本选择，支持主动降级。未签名下载不改变该基线。此约定不表示 OTA 安装结果已被系统确认：安装失败保留重试入口，旧包仍等现有安装结束信号后清理。

详情包含当前版本、来源、证书、版本更新设置、其他软件源提供的版本，以及本地包和历史版本。软件源包提供签名、安装、克隆、导出、信息和删除入口，手动导入包也可删除。

应用卡片长按「删除」，确认后清除该卡片的全部本地包和历史版本，包括所有软件源、手动导入包及归入该目标 ID 的原始未签名包；克隆与其他应用保留。详情的「操作 → 删除本地包」仅删除所选包，删掉当前包后按剩余包重新计算展示基线。两种操作均保留软件源订阅和更新偏好，不卸载桌面应用；可从软件源重新下载或手动导入。禁用软件源的包也允许显式手动删除，自动清理仍遵守禁用源保留规则。

删除前重新读取本地包与任务状态。同一应用有下载、排队、签名或安装任务占用时，暂不删除并说明原因，二次确认也不能绕过此检查。仅有持久化待安装保护时，在普通删除确认之后追加「放弃安装重试并删除？」；取消不改动包或保护，明确确认后才继续。确认绑定当前安装计划，期间计划发生变化时要求重新发起删除；任务重新开始时仍拦截。此操作只放弃本地包的重试，不声称取消已提交给 iOS 的安装。

删除文件及数据库记录成功后才移除对应引用；签名输出被删除时放弃其安装计划，删除单个输入或历史包时保留仍可重试的其他输出，其他应用和安装计划继续保留。文件或数据库错误显示实际删除数量和失败原因，失败包可重试；整卡遇到任务占用或未经确认的保护时不删除任何包。自动清理继续保护所有待安装包，不因列表显示“已安装”、冷启动或时间流逝而解锁。删除后同步重算更新候选和角标。

## 每应用 Bundle ID（2026-10-20）

2026-10-21 按用户确认，唯一的每应用编辑入口调整为「软件源 → 软件源设置 → 本机 Bundle ID → 选择应用」。普通与可管理的软件源都显示此入口，不依赖管理端点探测、Token 或远端连接成功；使用当前公开目录列出应用，同一原始 ID 的变体共用配置。默认使用原始 ID，支持恢复原始值。配置按原始 ID 保存于本机 UserDefaults，同一应用的不同版本、软件源和新导入包共用；保存只影响之后创建的签名任务，不自动签名或安装，不改写现有包或远端软件源。应用详情和签名页不再提供 ID 编辑，全局标识符替换入口移除。新签名记录保留可选的原始 ID，旧记录未保存此字段时以现存包的 ID 为基线。克隆生成自己的原始身份，后续克隆更新不覆盖父应用。

手动签名、自动导入、自动更新、续签和换证书重签都读取同一配置。明确保存的值优先于历史全局 ID 替换和 PPQ 后缀规则，恢复原始值也保留为显式配置；普通手动签名没有每应用配置时保留历史全局规则。软件源的手动签名固定读取本机配置，未配置时使用原始 ID；签名页只展示目标 ID，不再写回偏好。「签名并安装」保留来源的安装意图，关闭签名页后安装本次输出 UUID，即使全局签名后安装关闭仍继续；签名失败保留页面和重试，缺少或不匹配的输出不能安装旧包，来源中断仍抑制安装。

签名与证书选择按实际目标 ID 核对已有签名身份，不能通过填写另一个已有应用的 ID 绕过覆盖兼容检查。更新缓存只直接安装目标 ID 匹配的签名包，其他已下载包重新签名；软件源的打开入口使用配置后的 ID。手动导入后自定义 ID 的应用使用保留的原始 ID 继续匹配软件源，修改配置不切断已有更新关联。原始未签名包归入配置目标的本地包，详情、删除、下载进度及更新候选使用同一分组；已签名的不同 ID 和克隆仍按实际身份分卡，修改配置不把旧签名伪装为新目标已安装，不删除历史包。

## 多源候选和缓存

软件源之间、手动导入与软件源之间允许重复 Bundle ID，全部合并到一张应用卡片。启用源的当前发布版本共同参与选择；数值版本按组件比较，1.10 高于 1.9，正式版高于相同版本的预发布版，构建元数据和上传时间不证明版本更新。无法比较的格式只保留为详情中的手动选择，不自动覆盖。

较新候选中若最高版本存在多个来源，优先用户主动选择过的来源，其次当前包来源。没有可确定来源时提示在详情中选择一次。来源偏好只用于同版本排序，不阻止其他来源提供更高版本。暂停和跳过规则按应用处理。

缓存按仓库身份、订阅、来源版本和实际应用身份匹配；仓库 URL 迁移保持已有契约。同一仓库同 Bundle ID 的不同 IPA 订阅仍保持独立来源身份，不能混用缓存。缓存文件存在时复用本地包；需要换证书或重新激活较早签名的包时重新签名，不重复下载。源列表获取入口也使用同一缓存和签名队列策略。

软件源列表的“安装”在未下载和已有签名包待安装两种状态下，共用灰底、主题色文字的胶囊样式及至少 44pt 的点击高度。缓存状态只决定点击后下载或直接安装，不改变同名按钮的颜色和宽度；下载进度、“签名”和“打开”仍按各自状态展示。

冷启动重新取得当前会话的候选，避免上次检查时间仍在间隔内但内存候选为空。自动下载遵守 Wi-Fi、夜间、应用和来源的自动更新设置；主动更新沿用手动操作语义。检查未完成和未检查不会显示成已全部更新。

## 软件源开关与任务

软件源列表卡片的长按菜单提供“启用软件源”或“禁用软件源”，根据当前状态只显示对应操作，并保留移除入口。卡片禁用时显示“已禁用”；重新启用立即取消该标记并检查更新。开关为本机设置，与自动更新开关独立。关闭的软件源退出候选，保留本地包和默认列表展示；可打开、查看和导出，重新签名和安装需先启用。其他启用源仍能更新同一应用。开关变动使用已取得的目录立即重算候选，启用后继续刷新；不会按重复 Bundle ID 阻止启用。

禁用取消该源的排队任务与下载。正在签名的任务允许完成，保留结果，但不继续自动安装或重试，快速重新启用也不会恢复该被取消的任务。已经提交的安装继续。相同应用的新来源任务等待已有签名、导入和安装使用结束。服务端安装保留服务器及包使用记录，观测结束或等待窗口结束后释放，仍提供重新安装入口。

删除远端订阅成功后，清理该仓库及订阅对应的本地包和关联记录，其他来源、其他订阅和手动包保留。正在使用的输入延后清理；删除标记也覆盖之后产生的签名结果。旧记录仅在来源可明确关联且同 Bundle ID 订阅唯一时使用历史 Bundle ID 关联，避免误删变体。恢复远端备份成功时清除该源的删除标记。清理只影响 SignOs 数据，不卸载桌面应用。

安装自动清理保留已禁用来源的包。文件删除失败不先删除对应数据库记录，以便后续重试。

## 证书

更改默认证书不批量重签已有应用。已有应用更新继续使用原有效证书；替换时检查已签名包实际 entitlement 身份与新证书签名身份，核对 Team、App ID 前缀、签名 application-identifier、钥匙串组和 App Groups。签名 App ID 与 Bundle ID 是不同字段，不能据此改写包名。

实际签名身份从 Mach-O 签名的 entitlement slot 读取，保存到 Signed 的可选二进制记录。启动时补齐可验证旧记录，删除证书资料前保存身份，避免失去后续兼容性基线。未知或不兼容的原身份不自动覆盖。数据模型使用轻量迁移，保持原包、签名时间、导入和来源记录。

单个应用及批量提供更换证书并重新签名，复用本地包，不改版本和来源，不计入版本更新数量。禁用来源不能重签。签名失败不生成成功签名记录；失败保留包与重试入口。已有包未删除前不假设真实设备数据和钥匙串保留已被验证。
